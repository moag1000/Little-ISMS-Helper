# Dokumentationsübersicht

Technische Dokumentation, Anleitungen und Entscheidungsunterlagen des Little ISMS Helper.
Regeln für Entwickler und KI-Assistenten stehen in [`../CLAUDE.md`](../CLAUDE.md).

## Verzeichnisstruktur

| Verzeichnis | Inhalt |
|---|---|
| `setup/`, `deployment/` | Installation, Konfiguration, Produktions-Deployment |
| `user-guide/`, `admin/`, `sichtwechsel/` | Anleitungen für Anwender, Administratoren und Rollen-Perspektiven |
| `onboarding/` | Einstieg für neue Mitwirkende (siehe auch [`../ONBOARDING.md`](../ONBOARDING.md)) |
| `architecture/`, `adr/`, `decisions/` | Architektur, Architecture Decision Records |
| `superpowers/` | Design-Specs und aktive Pläne |
| `compliance/`, `tisax/` | Framework-Mappings, Audit-Berichte, Katalog-Analysen |
| `security/` | Sicherheitsarchitektur, OWASP-/CVE-Dokumentation |
| `operations/` | Backup, Disaster Recovery |
| `ui-patterns/`, `ui-ux/`, `design_system/` | UI-Muster, Design-System |
| `reports/` | Von der Anwendung gelesene bzw. generierte Berichte (Lizenz, OWASP) |
| `archive/` | Historische Dokumente, nicht gepflegt (siehe [`archive/README.md`](archive/README.md)) |

Skripte liegen unter `scripts/` (`setup/`, `quality/`, `tools/`); Details in
[`setup/SETUP_TOOLS.md`](setup/SETUP_TOOLS.md) und [`../scripts/README.md`](../scripts/README.md).
