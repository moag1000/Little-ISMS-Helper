**Ziel:** Marktführer bei DACH (DE/AT/CH) + EU Cross-Framework-Mappings. Spec: `docs/superpowers/specs/2026-06-12-dach-eu-mapping-leadership-design.md`. Plan P1: `docs/superpowers/plans/2026-06-12-nis2-bsi-mapping-quality.md`. Baut auf [[project_iso_bsi_gap]] (WS-5b-Pipeline).

**Leitprinzip:** best possible outcome (AI als Worker) — maximale Rigorosität + Vollständigkeit, nicht minimal-viable. **Vollständigkeit = wiederkehrender Loop** (loop-until-dry), jede Runde neu adressiert.

**Pipeline pro Mapping-Paar (5 Stages, in Runden):** (1) erschöpfendes amtliches Quellen-Sourcing (web-fetch, Integritäts-Guard, STOP-statt-fabrizieren), (2) Korroboration gegen Union der amtlichen Crosswalks, (3) framework-gematchtes Experten-Panel (2 Specialist-Skills laden `.claude/skills/<skill>/references/*.md` + 2 Lenses consultant/auditor) + **Refutations-Runde** (Skeptiker widerlegt jedes ki_validiert), (4) **Vollständigkeit** (fehlende Korrespondenzen → `panel_discovered`), (5) Apply + Completeness-Critic → nächste Runde bis K=2 dry.

**Trust-Tiers:** amtlich > amtlich_gestützt > ki_validiert (Konsens+überlebte Refutation) > bestaetigt > heuristisch. Neu: `panel_discovered`.
